# DishDac 
DishDac is an Android application that helps users discover and explore different recipes.

## Features
- Browse recipes by categories:
  - Tunisian 
  - Italian 
  - Healthy 
  - Sweets 
- Easy navigation between screens
- Simple and user-friendly design

## Technologies
- Java
- XML
- Android Studio

##  How to use
1. Open the app  
2. Choose a category  
3. Select a recipe  
4. Enjoy cooking
